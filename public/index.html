Ingestão geralvários itens, links e textos de uma vez

Cole qualquer coisa: uma linha por item, listas, links soltos, anotações. #doutorado, #edge e os outros hubs definem o hub; um título ## Doutorado vale para os itens abaixo. Itens marcados como feitos (- [x]) são ignorados.

🎤 Ditado: fale um item, diga “próximo item” para começar outro e “hashtag doutorado” (ou edge, pessoal…) para escolher o hub. Clique de novo no microfone para parar.
